## НЕ проверено (внешние зависимости)

1. **Настоящий LLM-провайдер**: ключ в секреты функции не заведён, помощник на живом сайте отвечает «не настроен». Проверены только подставная модель и сценарии ядра.
2. **Web Push**: VAPID-ключи и `DISPATCH_SECRET` не заведены, расписание `pg_cron` для `push-dispatch` не создано. Диспетчер проверен с подставным отправителем; доставка на устройство, iOS-установка не проверялись.
3. **liquid-gl**: включается только при реальном WebGPU; на реальном устройстве преломление не смотрелось. Базовое стекло — CSS `backdrop-filter`.
4. **iOS/Android-устройства**: установка PWA, startup-изображения, клавиатура, safe area проверены только эмуляцией Chromium.
5. **Отключение публичной регистрации** в Auth: через доступные средства не проверяется, это настройка в панели Supabase (см. `SETUP.md` §2). Без членства в `tenant_members` зарегистрированный пользователь ничего не видит.
6. Нагрузочные испытания не проводились.

## Известные ограничения

- **Деплой на Vercel собран нестандартно**: из этой среды нет доступа к GitHub и к Vercel CLI, поэтому проект Vercel при сборке забирает готовый `dist` из временного хранилища Supabase (бакет `deploy-src`, сейчас закрыт). Текущая версия сайта работает, но кнопка «Redeploy» в Vercel собрать её заново не сможет. Для постоянной работы: положить репозиторий в GitHub, подключить к Vercel, задать `VITE_SUPABASE_URL` и `VITE_SUPABASE_ANON_KEY`, а у проекта убрать нестандартные команды сборки (Build Command → `pnpm build`, Install Command → по умолчанию).
- Неизвестная студия (`/s/<нет-такой>/`) на Vercel отдаёт 404 хостинга, а не страницу приложения.
- Повторная публикация из файла перезаписывает поля, которыми управляет файл (название, цены, график): правки владельца в них сбросятся.
- Основной бандл ≈1 МБ (≈299 КБ gzip); Chrome предупреждает о размере. Кабинет владельца и liquid-gl вынесены в отдельные чанки.
- Фото демо-студий — временные сгенерированные картинки; замените реальными.
- Сборка берёт студии из папки `tenants/`: новая студия появляется на сайте после коммита и пересборки.
- Предупреждения линтера Supabase: у 11 внутренних функций схемы `private` не закреплён `search_path` (схема не опубликована через API); остальное — ожидаемые «публичные» функции записи.

## Следующий шаг до боевого запуска

Секреты (`LLM_*`, `VAPID_*`, `DISPATCH_SECRET`) → расписание Cron (`SETUP.md` §3) → GitHub + штатный деплой Vercel → смена пароля демо-владельца и выключение публичной регистрации → `tenant:verify <slug> --url … --activate` для боевых студий.
