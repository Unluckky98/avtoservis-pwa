## Проверено на живом помощнике (Groq, `openai/gpt-oss-120b`)

- Клиент: вопрос про услуги → инструмент `get_studio_info`, реальный прайс; вопрос про свободное время → `check_availability`; попытка выманить чужие записи и системный промпт → отказ без вызова инструментов.

4. **iOS/Android-устройства**: установка PWA, startup-изображения, клавиатура, safe area проверены только эмуляцией Chromium.
6. Нагрузочные испытания не проводились.

## Известные ограничения

- **Деплой на Vercel** теперь штатный: репозиторий `Unluckky98/avtoservis-pwa` подключён, сборка `pnpm build` (Node 22), переменные `VITE_SUPABASE_URL`, `VITE_SUPABASE_ANON_KEY`, `VITE_VAPID_PUBLIC_KEY` заданы в проекте; продакшен-деплой из GitHub проверен (адреса отвечают 200, ключ в бандле, стили на месте). Обходной деплой через временный бакет больше не нужен.
- Неизвестная студия (`/s/<нет-такой>/`) на Vercel отдаёт 404 хостинга, а не страницу приложения.
- Повторная публикация из файла перезаписывает поля, которыми управляет файл (название, цены, график): правки владельца в них сбросятся.
- Основной бандл ≈1 МБ (≈299 КБ gzip); Chrome предупреждает о размере. Кабинет владельца и liquid-gl вынесены в отдельные чанки.
- Фото демо-студий — временные сгенерированные картинки; замените реальными.
- Сборка берёт студии из папки `tenants/`: новая студия появляется на сайте после коммита и пересборки.
- Предупреждения линтера Supabase: у 11 внутренних функций схемы `private` не закреплён `search_path` (схема не опубликована через API); остальное — ожидаемые «публичные» функции записи.
